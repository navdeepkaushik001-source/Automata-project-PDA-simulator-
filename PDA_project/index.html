Formal Automata Theory Specification

A Pushdown Automaton (PDA) is formally defined as a 7-tuple: M = (Q, Σ, Γ, δ, q0, Z0, F)

Formal 7-Tuple Components

  • Q: Finite set of internal states.
  • Σ: Finite set of input symbols (Input Alphabet).
  • Γ: Finite set of stack symbols (Stack Alphabet).
  • δ: Transition function Q × (Σ ∪ {ε}) × Γ → P(Q × Γ*).
  • q0: Start/initial state (q0 ∈ Q).
  • Z0: Initial bottom-of-stack symbol (Z0 ∈ Γ).
  • F: Set of accepting states (F ⊆ Q).

Acceptance Modes

  • Acceptance by Final State L(M): Accepts if there exists a computation path from (q0, w, Z0) ⊢* (q, ε, γ) where q ∈ F and γ ∈ Γ*.
  • Acceptance by Empty Stack N(M): Accepts if (q0, w, Z0) ⊢* (q, ε, ε) for any state q ∈ Q. The stack must be emptied.
  • Equivalence Theorem: A language L is accepted by final state iff it is accepted by empty stack: L(M1) = N(M2).

DPDA vs. NPDA

  • DPDA: At most one valid transition from any configuration. Cannot accept all CFLs (e.g. even palindromes require NPDA).
  • NPDA: May branch nondeterministically. Recognizes the complete class of Context-Free Languages (CFLs).
  • This simulator implements Breadth-First Search (BFS) to exhaustively evaluate all computation branches of NPDAs without getting trapped in cycles.
